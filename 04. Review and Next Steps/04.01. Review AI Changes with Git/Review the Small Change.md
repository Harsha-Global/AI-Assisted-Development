# Review the small change

1. Inspect the changed-file list and diff against the request.
2. Run `python3 check_search.py` on that same working copy; expect 7/7 passing checks after the fix.
3. Investigate any failed result or unexpected file change.
4. Stage the reviewed source and inspect the staged diff.
5. Commit locally. If you share it, push to your own GitHub repository and inspect that same commit there.

Use Commands.txt for the command reference. The explanation, diff, observed program results and saved history establish different facts; consider them together.
