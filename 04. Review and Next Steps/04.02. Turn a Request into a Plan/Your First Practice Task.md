# Choose your first practice task

Pick one small change whose code and behavior you understand. Use a suitable practice copy and your team's rules for sharing code and data.

- What result do you want?
- Which code and inputs will help the assistant understand it?
- What should remain unchanged?
- What will you inspect or run before accepting the result?
- What did the tool help with, and what decision did you make yourself?

Keep the task manageable. Larger work calls for continued practice with project context, testing, security, review and delivery. This reflection is a starting point, not a guarantee of professional mastery or job security.
