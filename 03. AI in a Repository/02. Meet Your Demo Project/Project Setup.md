# Project setup - AI-Assisted Development: A Practical Introduction

Course resources: https://github.com/Harsha-Global/AI-Assisted-Development

Download the repository using Code > Download ZIP, or clone it with Git.
Open the course's Download and Set Up the Project article for exact copy/setup commands.

## Choose the right starting files

- Before the search fix: [Starter project](https://github.com/Harsha-Global/AI-Assisted-Development/tree/main/03.%20AI%20in%20a%20Repository/02.%20Meet%20Your%20Demo%20Project/Starter).
- After the reviewed search fix, before planning the command-line feature: [Reviewed search fix](https://github.com/Harsha-Global/AI-Assisted-Development/tree/main/03.%20AI%20in%20a%20Repository/04.%20Your%20First%20AI%20Code%20Change/Completed).
- Finished command-line feature: [Completed command-line feature](https://github.com/Harsha-Global/AI-Assisted-Development/tree/main/04.%20Review%20and%20Next%20Steps/03.%20Build%20a%20Feature%20You%20Can%20Use/Completed).

Copy the contents of the chosen source folder to a separate practice folder.
Open that practice folder in your editor and terminal. Initialize Git there if you want to follow the diff/commit demonstrations. Keep the downloaded course materials as your reference copy.

Run `python3 demo.py` and `python3 check_search.py`. On Windows with the launcher, use `py -3` instead of `python3`.
The Starter is expected to report 6/7 passing checks: its padded-query check fails.
The reviewed fix and completed CLI are expected to pass all 7 checks.

For the AI interaction, install and sign in to Claude Code using the [official quickstart](https://code.claude.com/docs/en/quickstart), then run `claude` from the practice project folder. The subscription route used in this course requires paid Claude Code access, such as Claude Pro. No third-party Python packages or separate API setup are needed for the sample.

If you publish your practice changes, use a repository in your own GitHub account.
The video shows the repository used during recording; the current student resources are maintained under Harsha-Global at the link above.
