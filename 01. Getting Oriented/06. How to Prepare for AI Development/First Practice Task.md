# Choose a first practice task

Use one familiar, bounded task in a sample or disposable project copy, following your team's code/data rules. You should be able to describe and check its result. You do not need to master every tool first.

## Example to adapt

Problem: a notes search handles different letter cases, but outer spaces cause an unexpected no-match.

Desired behavior: ignore spaces around the query. Preserve existing case-insensitive matching.

Context: relevant function, example input, required behavior and constraints. This is a suggested practice example, not an executed model result or a completed code solution.

Evidence to gather: the actual changed lines, relevant check results, any correction you made, and why you accepted the outcome. Compare the whole task's effort, including review and correction.
