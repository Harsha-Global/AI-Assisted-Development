# Chat and coding-agent glossary

| Term | Meaning in this course |
| --- | --- |
| AI-assisted development | Using AI assistance during software work, including requirements, design, implementation, verification and maintenance |
| Context | The information available for a task: instructions, code, examples, files or tool results |
| Suggestion | Proposed text/code; it may not yet be applied to the project |
| Inline suggestion | A proposal shown in an editor; appearance alone does not establish that it was applied |
| Coding agent | An assistant that can use available, authorized tools to work through project actions and use their results |
| Applied change | An actual edit to project files, still needing inspection and relevant checks |
| Check evidence | An observed result for a particular behavior; its scope matters |
| Git diff | A comparison showing changed lines; it is not proof that the program works |
| Local repository | A Git repository on the machine; in this course it is a clone of the project hosted on GitHub |

In our later ChatGPT example, we supply a snippet without connecting the chat to the local project. In the Claude Code example, the tool works with project files. These are course setups, not exhaustive product limitations. Codex is another coding agent, introduced only by name here.

GitHub hosts the course project and its shared history. The coding agent works in the local clone; hosting code does not automatically grant an AI chat access to it.
