# Tools and access

AI-Assisted Development: A Practical Introduction is for developers with code/project experience and basic Git knowledge.
Use Git, Python 3, a code editor and Claude Code CLI for the repository exercises.
The sample uses only the Python standard library.

Paid Claude Code access, such as Claude Pro, is needed for the course's subscription-based agent workflow. ChatGPT Free and GitHub Free are sufficient for their parts. No advanced Python or prior AI/ML knowledge is required.

Install Claude Code and check supported platforms using the [official quickstart](https://code.claude.com/docs/en/quickstart).
Open the course's Before You Start and Download and Set Up the Project articles for the student workflow.

Course resources: https://github.com/Harsha-Global/AI-Assisted-Development
