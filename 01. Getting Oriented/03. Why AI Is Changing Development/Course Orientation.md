# AI-Assisted Development: A Practical Introduction

Understand AI workflows and developer roles, then explore ChatGPT and Claude Code through practical GitHub demos.

This is a brief practical introduction for existing developers across languages and frameworks. Project and Git experience is assumed; no prior AI knowledge is required.

## The wider landscape

AI can assist with requirements, project exploration and design, implementation, verification, delivery and maintenance. Assistance can appear through conversations, editor suggestions and coding agents with project tools. Capabilities depend on context, tools and permissions. Developing with AI does not require adding AI features to the application.

## The four sections

1. **Getting Oriented:** the landscape, origins, current direction, developer roles and preparation.
2. **Talking to AI:** a ChatGPT example about useful context, requests and inspecting assumptions.
3. **AI in a Repository:** Claude Code explores a small GitHub project's local clone and makes a focused fix.
4. **Review and Next Steps:** review with Git, plan and build a usable command-line feature, then connect the small examples to enterprise work and further learning.

## Outcomes and expectations

Follow the request, context, plan, file changes, checks and review in one small project. Use that example to choose a first practice task whose code and behavior you understand.

The closing maps the small demonstrations to requirements and architecture, context engineering, supervised agent workflows, skills/hooks/MCP, testing, enterprise controls, delivery and monitoring. These are introductory explanations of purpose and relationships. Confidence across larger systems calls for connected projects, repeated practice, failure investigation and review feedback.

The booking story illustrates the wider workflow; the practical code is the separate developer-notes project.

## Requirements

- Experience writing code and working with an existing software project.
- Basic Git familiarity, including cloning a repository, inspecting a diff and committing changes.
- Paid Claude Code access, such as Claude Pro, for practising the repository demonstrations.
- Free ChatGPT and GitHub accounts are sufficient for their parts; ChatGPT Plus and GitHub Pro are not required.
- Install Claude Code CLI, Git and Python 3, and use your preferred code editor. See the setup notes for supported operating systems.
- No prior AI or machine-learning knowledge is required; advanced Python knowledge is not needed.
