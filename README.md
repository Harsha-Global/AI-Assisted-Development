Copy the chosen source folder into a separate practice folder. Run commands from that source folder, not from the repository root. No Python packages are needed. Use python3 on macOS/Linux or py -3 on Windows.

Keep your own work separate from the reference snapshots. If you push your practice commits, use a repository in your own GitHub account.
The repository visible in the recorded videos was used for that demonstration; this Harsha-Global repository is the current student-resource location.
